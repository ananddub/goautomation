# Go Automation Client

This is the Go version of the Python automation client for RabbitMQ-based RPC communication with SQLite database integration using sqlc.

## Project Structure

```
goautomation/
├── client/
│   └── client.go           # Client package with automation functions
├── db/
│   ├── migrations/         # Database schema migrations
│   ├── queries/           # SQL queries for sqlc
│   ├── sqlc/             # Generated Go code from sqlc
│   └── database.go       # Database connection helper
├── data/                 # SQLite database files (created at runtime)
├── main.go              # Main application entry point
├── go.mod               # Go module dependencies
├── sqlc.yaml           # sqlc configuration
├── Makefile            # Build and development commands
└── README.md           # This file
```

## Setup

1. Install dependencies:
```bash
go mod tidy
```

2. Install sqlc (if not already installed):
```bash
go install github.com/sqlc-dev/sqlc/cmd/sqlc@latest
```

3. Generate database code (if you modify SQL queries):
```bash
make sqlc-generate
# or
sqlc generate
```

4. Run the client:
```bash
make run
# or
go run main.go
```

## Features

- **MoveMouse**: Move mouse to specified position
- **ClickMouse**: Click mouse at specified position  
- **GetPixelColor**: Get pixel color at specified position
- **Database Logging**: All automation actions are logged to SQLite database
- **Query Interface**: Type-safe database queries generated by sqlc

## Database Schema

The application uses SQLite to store automation logs with the following schema:

```sql
CREATE TABLE automation_logs (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    action_type TEXT NOT NULL,
    x_position REAL,
    y_position REAL,
    pixel_color TEXT,
    timestamp DATETIME DEFAULT CURRENT_TIMESTAMP,
    success BOOLEAN DEFAULT TRUE,
    error_message TEXT
);
```

## Usage Example

```go
package main

import (
    "database/sql"
    "log"
    "goautomation/client"
    "goautomation/db"
    "goautomation/db/sqlc"
)

func main() {
    // Initialize database
    database, err := db.NewDatabase("./data/automation.db")
    if err != nil {
        log.Fatal(err)
    }
    defer database.Close()

    // Create client
    automationClient, err := client.NewAutomationRPCClient("")
    if err != nil {
        log.Fatal(err)
    }
    defer automationClient.Close()

    // Get pixel color
    response, err := automationClient.GetPixelColor(
        client.StringPtr("1"), 
        client.Float64Ptr(0.62), 
        client.Float64Ptr(0.92),
    )

    // Log to database
    logParams := sqlc.CreateAutomationLogParams{
        ActionType: "GetPixelColor",
        XPosition:  sql.NullFloat64{Float64: 0.62, Valid: true},
        YPosition:  sql.NullFloat64{Float64: 0.92, Valid: true},
        Success:    err == nil && response.Success,
    }
    
    database.Queries.CreateAutomationLog(database.DB, logParams)
}
```

## Configuration

- Default RabbitMQ URL: `amqp://34.56.24.250:5672`
- Default User queue: `raiboss1`
- Database file: `./data/automation.db` (created automatically)
- You can override RabbitMQ URL by passing custom values to `NewAutomationRPCClient(customURL)`

## Database Queries

The following queries are available through the generated sqlc interface:

- `CreateAutomationLog`: Insert a new automation log
- `GetAutomationLog`: Get a specific log by ID
- `ListAutomationLogs`: Get recent logs (with limit)
- `ListAutomationLogsByAction`: Get logs filtered by action type
- `GetRecentAutomationLogs`: Get logs from the last hour
- `DeleteOldAutomationLogs`: Clean up logs older than 7 days
- `CountAutomationLogsByAction`: Count logs by action type
